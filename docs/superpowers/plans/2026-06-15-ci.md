# CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub Actions CI with SwiftLint, build, and unit test jobs triggered on PRs to `main`, running on a self-hosted macOS runner with Xcode 26.

**Architecture:** Three GitHub Actions jobs — `lint` and `build` run in parallel, `test` depends on `build`. A new `XCUIPlaygroundTests` unit test target is added to the Xcode project. SwiftLint runs against the `XCUIPlayground/` source directory.

**Tech Stack:** GitHub Actions, xcodebuild, SwiftLint, xcpretty, iOS 26 Simulator

## Task 4: GitHub Actions CI Workflow

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Create the workflow file**

Write to `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  pull_request:
    branches:
      - main

jobs:
  lint:
    name: SwiftLint
    runs-on: self-hosted
    steps:
      - uses: actions/checkout@v4

      - name: Install SwiftLint
        run: which swiftlint || brew install swiftlint

      - name: Run SwiftLint
        run: swiftlint lint --reporter github-actions-logging

  build:
    name: Build
    runs-on: self-hosted
    steps:
      - uses: actions/checkout@v4

      - name: Install xcpretty
        run: gem install xcpretty --no-document 2>/dev/null || true

      - name: Build
        run: |
          set -o pipefail
          xcodebuild build \
            -project XCUIPlayground.xcodeproj \
            -scheme XCUIPlayground \
            -destination 'platform=iOS Simulator,OS=latest,name=iPhone 16' \
            CODE_SIGNING_ALLOWED=NO \
            CODE_SIGNING_REQUIRED=NO \
            CODE_SIGN_IDENTITY="" \
            | xcpretty

  test:
    name: Unit Tests
    runs-on: self-hosted
    needs: build
    steps:
      - uses: actions/checkout@v4

      - name: Install xcpretty
        run: gem install xcpretty --no-document 2>/dev/null || true

      - name: Run Tests
        run: |
          set -o pipefail
          xcodebuild test \
            -project XCUIPlayground.xcodeproj \
            -scheme XCUIPlayground \
            -destination 'platform=iOS Simulator,OS=latest,name=iPhone 16' \
            CODE_SIGNING_ALLOWED=NO \
            CODE_SIGNING_REQUIRED=NO \
            CODE_SIGN_IDENTITY="" \
            | xcpretty
```

- [ ] **Step 2: Commit**

```bash
git add .github/workflows/ci.yml
git commit -m "Add GitHub Actions CI workflow"
```

## Self-Hosted Runner Prerequisites

The runner Mac must have:
- Xcode 26 installed and selected (`sudo xcode-select -s /Applications/Xcode.app`)
- iOS 26 Simulator runtime installed
- Homebrew installed (for SwiftLint install step)
- The `iPhone 16` simulator created (or update destination in workflow)
- GitHub Actions runner configured and connected to the repo

To verify on the runner:
```bash
xcodebuild -version          # should show Xcode 26.x
xcrun simctl list runtimes   # should include iOS 26
swiftlint version            # if pre-installed
```
