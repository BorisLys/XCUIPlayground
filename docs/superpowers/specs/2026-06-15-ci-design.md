# CI Design — XCUIPlayground

**Date:** 2026-06-15

## Summary

Add GitHub Actions CI with three jobs: lint, build, and unit tests. Triggered on PRs to `main`. Runs on self-hosted macOS runner with Xcode 26.

## 1. Xcode Unit Test Target

Add `XCUIPlaygroundTests` as a Unit Testing Bundle target to `XCUIPlayground.xcodeproj`:

- Host application: `XCUIPlayground`
- Linked to the `XCUIPlayground` scheme's Test action
- One starter file: `XCUIPlayground/XCUIPlaygroundTests/XCUIPlaygroundTests.swift` with a single smoke test

## 2. SwiftLint

Add `.swiftlint.yml` at the project root:

```yaml
disabled_rules:
  - trailing_whitespace
  - line_length
  - todo

opt_in_rules:
  - force_cast
  - force_try
  - unused_import
  - empty_count

included:
  - XCUIPlayground
```

Self-hosted runner installs SwiftLint via `brew install swiftlint` if not already present.

## 3. CI Workflow

File: `.github/workflows/ci.yml`

**Trigger:** `pull_request` targeting `main`

**Jobs:**

| Job | Depends on | Description |
|-----|-----------|-------------|
| `lint` | — | SwiftLint across `XCUIPlayground/` |
| `build` | — | `xcodebuild build` iOS Simulator |
| `test` | `build` | `xcodebuild test` iOS Simulator |

All jobs: `runs-on: self-hosted`

Destination for build and test:
```
platform=iOS Simulator,OS=latest,name=iPhone 16
```

**lint job steps:**
1. `actions/checkout@v4`
2. `brew install swiftlint || true`
3. `swiftlint lint --reporter github-actions-logging`

**build job steps:**
1. `actions/checkout@v4`
2. `xcodebuild build -project XCUIPlayground.xcodeproj -scheme XCUIPlayground -destination '...' | xcpretty`

**test job steps:**
1. `actions/checkout@v4`
2. `xcodebuild test -project XCUIPlayground.xcodeproj -scheme XCUIPlayground -destination '...' | xcpretty`
